## Descricao

Criar o design system premium do frontend.

- [ ] Vite + Preact + TypeScript configurado
- [ ] CSS custom properties para theming (light + dark)
- [ ] Variaveis de design: cores, espacamento, tipografia, bordas, sombras
- [ ] Tema dark: fundo tinted charcoal (#0b0d10), nao preto puro
- [ ] Tema light: off-white (#f7f8fa), nao branco puro
- [ ] Glassmorphism em elementos fixos (sidebar, topbar)
- [ ] Tipografia premium (Plus Jakarta Sans ou Geist)
- [ ] Tabular nums para metricas (font-variant-numeric: tabular-nums)
- [ ] Cores de status via tokens (success/warn/danger/info)
- [ ] Skeleton loaders (nao texto Loading...)
- [ ] Transicoes com cubic-bezier customizado
- [ ] prefers-reduced-motion respeitado

## Definicao de Done
- [ ] Tema persiste em localStorage, sem FOUC
- [ ] Dark/light toggle funcional
- [ ] Todos os componentes usam CSS variables
- [ ] Audit de acessibilidade (axe) sem erros criticos
